==================================== Summarizing the Data ====================================
1. To compare the inverters to each other, and to help summarize their raw data, I have found it
   useful to create one file for each month that stores the average active power data for each of
   the 75 inverters for that month together.
   Data_Analysis\ActivePowerAverages\Unfiltered\MakeAvgAPCSV.py

2. The raw data can be cleaned up a little by removing days that reported mostly zeros. These days
   should not be forgotten, because it is possible that the panels really weren't generating power.
   But for the purposes of finding issues specifically related to shading as the sun sets, it is
   more helpful to remove these days. The following file does the same thing as the file above,
   except it removes these zero days in the process.
   Data_Analysis\ActivePowerAverages\FaultyDataDaysRemoved\MakeAvgAPCSV.py

3. I have thought about making a separate summary file generator that removes days that were likely
   cloudy. As of writing, this is incomplete and I am unsure if I will return to it. The irradiance
   detector was missing some data, which makes it difficult to use as a reliable way to find cloudy
   days. For reference, the data id is '27986'.
   I could try to access a weather api and look at past data to find cloudy days. This could cost
   money and might also be unnecessary, because the quantity of data could make up for cloudy day
   data. It could still be worth a try though.

==================================== Analyzing the Data ====================================
1. For each inverter in a month, the steepest negative slope formed by any 5 consecutive data points
   is calculated and stored in a new file, along with the time of the first of these 5 data points.
   As far as I have seen, this slope always occurs near the beginning of the sunset drop. The data used
   to calculate these slopes are the files that store the average active power of each inverter across a
   month (see Summarizing the Data).
   Data_Analysis\MathingIt\FindDropSlopes.py

2. For each inverter in a month, a quadratic of best fit is found for all the data points from the
   time that the steepest downward slope begins (found above) until the first time zero power is
   generated, endpoints inclusive. From this quadratic, ax^2 + bx + c, the second derivative is
   calculated (2 * a) for each inverter and stored in a new file.
   Data_Analysis\MathingIt\FindConcavity.py

3. So far, I have three ideas for characteristics that inverters affected by shade during sunset may have.
   a. They may have steeper slopes at the beginning of the sunset drop.
   b. Their sunset drops may start earlier than usual.
   c. Their sunset drops' concavities may be greater than usual.
   
   I haven't yet developed a way to store the results of these analyses for the inverters. I am
   considering a 3D table. The first two dimensions (not that it really matters) are the inverters
   and the ideas above. The third dimension is time. So something like this (fake data and only the
   layer for July 2025):
   JULY2025     Inv 1   Inv 2   ...     Inv 75
   Slope        N       N               Y
   Time         N       N               Y
   Concavity    N       Y               Y
